# Принятие решений при многих критериях: Метод ЭЛЕКТРА I (Вариант 6)

Реализация системы многокритериальной оптимизации и поддержки принятия решений для лабораторной работы по дисциплине «Базы знаний и поддержка принятия решений».

## 1. Постановка задачи (Вариант 6)

Предприятие предполагает заключить договор о поставках железной руды с одним из шести потенциальных поставщиков (**П1** – **П6**). Выбор осуществляется по трем критериям:
1. **Содержание металла в руде (%)** — критерий максимизации ($\uparrow$).
2. **Стоимость руды (ден.ед./тонну)** — критерий минимизации ($\downarrow$).
3. **Надежность поставок** — качественный критерий (максимизация $\uparrow$).

### Исходные характеристики поставщиков:
| Поставщик | Содержание металла, % | Стоимость, ден.ед./т | Надежность поставок |
| :---: | :---: | :---: | :---: |
| **П1** | 12 | 200 | возможны нарушения |
| **П2** | 9  | 120 | высокая |
| **П3** | 15 | 220 | очень высокая |
| **П4** | 8  | 120 | достаточно высокая |
| **П5** | 7  | 100 | высокая |
| **П6** | 10 | 140 | высокая |

Эксперты оценивают важность критериев следующим образом:
- **Эксперт 1**: наиболее важный — содержание металла (3), далее — надежность (2), наименее важный — стоимость руды (1).
- **Эксперт 2**: наиболее важный — содержание металла (3), далее — стоимость руды (2), наименее важный — надежность (1).

## 2. Краткое математическое решение

Решение выполняется поэтапно:
1. **Оцифровка качественных оценок**: перевод словесных градаций надежности в числовые коэффициенты по шкале Харрингтона:
   - *«возможны нарушения»* $\to 0.30$
   - *«достаточно высокая»* $\to 0.65$
   - *«высокая»* $\to 0.80$
   - *«очень высокая»* $\to 0.95$
2. **Построение множества Парето**: попарное сравнение всех альтернатив. Альтернатива **П4** полностью доминируется альтернативой **П2** (у П2 лучше содержание металла: 9% против 8%, выше надежность: 0.8 против 0.65 при одинаковой стоимости 120 ден.ед./т) и исключается из рассмотрения. Множество Парето: **{П1, П2, П3, П5, П6}**.
3. **Определение весов критериев (метод ранга)**:
   - Суммарные баллы: Металл = $3 + 3 = 6$, Стоимость = $1 + 2 = 3$, Надежность = $2 + 1 = 3$.
   - Веса: $w_1 = 0.50$, $w_2 = 0.25$, $w_3 = 0.25$.
4. **Нормализация оценок**:
   - Для максимизации: $r_{ik} = \frac{x_{ik}}{\max x_k}$
   - Для минимизации (стоимость): $r_{ik} = \frac{\min x_k}{x_{ik}}$
5. **Метод ЭЛЕКТРА I**:
   - Расчет матриц согласия $C = [c_{ij}]$ и несогласия $D = [d_{ij}]$.
   - Формирование графа предпочтений при пороговых значениях $c^*$ и $d^*$.
   - Выделение ядра недоминируемых решений.

## 3. Структура проекта и описание модулей

Проект декомпозирован на независимые модули:

- **`electre_core.py`** — ядро математических вычислений:
  - `find_pareto_set(data, is_max)`: находит Парето-оптимальные альтернативы с учетом векторов максимизации и минимизации.
  - `calc_weights_by_rank(ranks)`: вычисляет нормализованные веса критериев по экспертным рангам.
  - `normalize_matrix(data, is_max)`: приводит разнородные метрики к безразмерному базису $[0; 1]$.
  - `run_electre(...)`: строит матрицы согласия/несогласия и формирует ядро при заданных $c^*$ и $d^*$.
- **`data_variant6.py`** — модуль конфигурации данных Варианта 6: содержит имена, матрицы оценок, ранги экспертов и целевые векторы оптимизации.
- **`gui.py`** — модуль графического интерфейса:
  - Интерактивные слайдеры управления порогами $c^*$ и $d^*$.
  - Кнопки быстрых пресетов.
  - Текстовый протокол расчетов в реальном времени.
  - Автоматическая адаптация: использует библиотеку `customtkinter` с современным темным/светлым оформлением, а при ее отсутствии бесшовно переключается на встроенный `tkinter`.
- **`main.py`** — точка входа, связывающая данные и пользовательский интерфейс.
